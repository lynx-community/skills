# Getting Started

## 1. Install the CLI

agent-lynx requires Node.js 18.19 or later. Install the public npm package:

```bash
npm install -g agent-lynx
agent-lynx --help
```

If you have pnpm, you can run the CLI without a global installation:

```bash
pnpx agent-lynx --help
```

The following commands use `agent-lynx`. Replace it with `pnpx agent-lynx` if you use the one-shot command.

## 2. Prepare and Connect a Device {#prepare-device}

Choose a platform and how to connect to the app.

<PlatformTabs>

<PlatformTab platform="android" label="Android" connection="USB">

1. Install Android Platform Tools, enable **USB debugging** on the device, and connect it over USB. Accept the debugging prompt on the device.
2. Run `adb devices` and check that its status is `device`.
3. Open the app with Lynx DevTool enabled and load a Lynx page.

You can also get the app’s `CLIENT_ID` from `list-clients` and open the page with `agent-lynx open "$BUNDLE_URL" --client "$CLIENT_ID"`.

</PlatformTab>

<PlatformTab platform="android" label="Android" connection="Remote">

Set `ADB_ADDRESS` to the remote ADB address (`host:port`). Choose a device from `adb devices` and set `SERIAL`. Use the app’s launch component (`package/Activity`) as `APP_COMPONENT`, its package as `APP_PACKAGE`, and a page link it handles as `SCHEMA`.

```bash
adb connect "$ADB_ADDRESS"
adb devices # Output excerpt: $SERIAL  device
adb -s "$SERIAL" shell am start -n "$APP_COMPONENT"
adb -s "$SERIAL" shell am start -a android.intent.action.VIEW -d "'$SCHEMA'" "$APP_PACKAGE"
```

Once the app is running, you can also select it from `list-clients` and open the page with `agent-lynx open "$BUNDLE_URL" --client "$CLIENT_ID"`.

</PlatformTab>

<PlatformTab platform="ios" label="iOS" connection="USB">

1. Connect the iPhone or iPad to your computer over USB, unlock it, and trust the computer on the device.
2. Open the app with Lynx DevTool enabled and load a Lynx page.

You can also get the app’s `CLIENT_ID` from `list-clients` and open the page with `agent-lynx open "$BUNDLE_URL" --client "$CLIENT_ID"`.

</PlatformTab>

<PlatformTab platform="ios" label="iOS" connection="Remote">

The public CLI discovers iOS devices over USB. For a remote device, run `agent-lynx` and the inspection commands below on the computer connected to it. Open a Lynx page in the app on the device.

You can also get the app’s `CLIENT_ID` from `list-clients` and open the page with `agent-lynx open "$BUNDLE_URL" --client "$CLIENT_ID"`.

</PlatformTab>

<PlatformTab platform="desktop" label="Desktop">

Open your Desktop app on this computer and load a Lynx page.

You can also get the app’s `CLIENT_ID` from `list-clients` and open the page with `agent-lynx open "$BUNDLE_URL" --client "$CLIENT_ID"`.

</PlatformTab>

</PlatformTabs>

## 3. Inspect the Page {#inspect-page}

After opening a Lynx page, run these commands in order.

```bash
agent-lynx list-clients # Output excerpt: [{ "id": "$CLIENT_ID" }]
agent-lynx list-sessions --client "$CLIENT_ID" # Output excerpt: [{ "session_id": $SESSION_ID }]
agent-lynx snapshot --client "$CLIENT_ID" --session "$SESSION_ID"
agent-lynx screenshot --client "$CLIENT_ID" --session "$SESSION_ID" --annotate -o ./page.jpeg
```

Set `CLIENT_ID` to the full `id` returned by `list-clients`. In the `list-sessions` output, choose the Lynx page by URL and set `SESSION_ID` to its `session_id`. The annotated screenshot refreshes the snapshot and labels the elements with their refs. Next, try [Page Inspection and Interaction](page-inspection.mdx).

## 4. Give Your Agent the Instructions

agent-lynx ships with skills that the agent can discover and read directly:

```bash
agent-lynx skills list
agent-lynx skills get lynx-devtool
```

`skills get` returns the instructions and lists the skill's reference and example files. It does not install a skill into your project. To make the DevTool skill available through your agent's automatic skill discovery, see [lynx-devtool](/ai/skills/lynx-devtool).
